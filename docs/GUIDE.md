## 1. ลูกค้า: สั่งอาหารผ่าน QR

<img src="screenshots/c01-menu.png" width="220" align="right" alt="หน้าเมนู">

1. **ต่อ WiFi ของร้าน** แล้วสแกน QR บนโต๊ะด้วยกล้องมือถือ หน้าเมนูจะเปิดพร้อมเลขโต๊ะ ไม่ต้องลงแอป ไม่ต้องสมัครสมาชิก
2. **เลือกอาหาร** ได้ 2 วิธี:
   - **เร็ว:** กดปุ่ม **+** มุมขวาล่างของการ์ด ได้จานปกติ 1 จาน กดซ้ำเพื่อเพิ่มจำนวน
   - **ละเอียด:** แตะรูปหรือชื่ออาหาร เพื่อดูรายละเอียด ปรับจำนวน และเลือกหมายเหตุ
   - แถว **เมนูแนะนำ** ด้านบน (เลื่อนซ้าย-ขวา) คือเมนูที่ร้านแนะนำ กด **+** ได้เหมือนกัน
3. **เปลี่ยนหมวด:** แตะชื่อหมวดแถบบน (จานเดียว, ต้ม ยำ แกง …) เพื่อกระโดดไปหมวดนั้น หรือเลื่อนลงดูทุกหมวดก็ได้
   - **ค้นหา:** พิมพ์ชื่อเมนูในช่อง **ค้นหาเมนู…** เช่น "ผัด" หรือ "กุ้ง" กด **×** เพื่อกลับมาดูทั้งหมด
   - **แถบล่าง:** **เมนู** กลับขึ้นบนสุด · **ออเดอร์** ไปดูสถานะอาหารของโต๊ะ (ตัวเลข = ที่ยังไม่ได้เสิร์ฟ) · **ร้าน** ดูที่อยู่ เบอร์โทร เวลา ติดตามร้าน และแชร์ร้าน

<br clear="right">

<img src="screenshots/c03-detail-notes.png" width="220" align="right" alt="หมายเหตุ">

4. **ในหน้ารายละเอียด:**
   - กด **−** / **+** ปรับจำนวน
   - แตะแท็บ **หมายเหตุ** เลือกได้หลายข้อ เช่น ไม่เผ็ด ไม่ใส่ผัก
   - กด **เพิ่มรายการ** (ปุ่มแสดงราคารวมตามจำนวน)
   - จะกลับหน้าเมนูก็กดปุ่ม **<** มุมซ้ายบน หรือปุ่มย้อนกลับของมือถือ
5. **สั่งจานเดียวกันแต่ต่างกัน** เช่น กะเพรา "ไม่เผ็ด" 1 จาน กับ "เผ็ดมาก" 1 จาน ให้เพิ่มรายการทีละแบบ ระบบแยกให้ ครัวจึงรู้ว่าจานไหนเป็นแบบไหน

<br clear="right">

<img src="screenshots/c05-cart.png" width="220" align="right" alt="รายการสั่ง">

6. **ตรวจรายการ:** แตะแถบ **ดูรายการสั่ง** ด้านล่าง
   - แก้จำนวน (−/+) หรือแตะ **แก้หมายเหตุ** / **+ เพิ่มหมายเหตุ**
   - เขียน **ข้อความถึงครัว** ได้ เช่น แพ้ถั่ว ขอจานเปล่า
   - ตรวจยอดรวม (ยังไม่รวมค่าบริการ/ภาษี)
7. **กด สั่งอาหาร** ออเดอร์เข้าครัวทันที มีข้อความ "ส่งออเดอร์เข้าครัวแล้ว"
   - ถ้าเน็ตสะดุด ให้กดสั่งอีกครั้งได้ ระบบไม่ส่งซ้ำ
   - ถ้าราคาเมนูเพิ่งเปลี่ยน ระบบแสดงยอดใหม่ให้ตรวจ แล้วกดสั่งอีกครั้ง

<br clear="right">

<img src="screenshots/c06-order-status.png" width="220" align="right" alt="สถานะออเดอร์">

8. **ดูสถานะอาหาร:** เลื่อนลงล่างสุดที่ **ออเดอร์ของโต๊ะนี้**
   - สถานะเปลี่ยนเอง: **รอทำ → กำลังทำ → พร้อมเสิร์ฟ → เสิร์ฟแล้ว**
   - มียอดอาหารรวม และยอดประมาณการรวมค่าบริการ/VAT
9. **ต้องการพนักงาน:** กด **เรียกพนักงาน** หรือ **ขอเช็คบิล** หน้าร้านจะเห็นทันที
10. **สั่งเพิ่ม:** ทำแบบเดิมได้เรื่อยๆ จนกว่าร้านจะปิดบิลโต๊ะนั้น
<img src="screenshots/c11-shop-info.png" width="220" align="right" alt="ข้อมูลร้าน">

11. **ติดตามและแชร์ร้าน:** แตะ **ร้าน** ที่แถบล่าง กดปุ่ม Facebook / Instagram / LINE / TikTok เพื่อติดตามร้าน หรือกด **แชร์ร้านนี้** ส่งให้เพื่อน (ส่งลิงก์ของร้าน ไม่ใช่ QR ของโต๊ะ)

<br clear="right">

> **ลูกค้าเห็น "ร้านปิดรับออเดอร์ผ่าน QR ชั่วคราว" หรือ "นอกเวลารับออเดอร์"** ดูเมนูได้แต่สั่งไม่ได้ ให้เรียกพนักงานสั่งแทน
> **ลูกค้าเห็น "โต๊ะนี้ยังไม่ได้เปิด"** (ร้านเปิดโหมดต้องเปิดโต๊ะ) ให้กด **เรียกพนักงาน** พนักงานกดเปิดโต๊ะแล้วสั่งได้ทันทีโดยไม่ต้องรีเฟรช
> **ลูกค้าเห็น "QR ของโต๊ะไม่ถูกต้อง"** QR แผ่นนั้นถูกเปลี่ยนรหัสแล้ว ให้สแกนแผ่นใหม่ที่โต๊ะ
> **ลูกค้าเห็นป้าย "สัญญาณหลุด"** ให้ตรวจว่ายังต่อ WiFi ร้านอยู่ ป้ายจะหายเองเมื่อต่อได้

## 2. เข้าและออกจากระบบ

<img src="screenshots/s01-login.png" width="220" align="right" alt="หน้าเข้าสู่ระบบ">

1. **เข้าระบบ:** เปิดหน้าพนักงาน (`/staff`) ใส่ **PIN ของตัวเอง** (ตัวเลข 6–8 หลัก ที่เจ้าของร้านตั้งให้) แตะตัวเลขบนแป้นในจอได้เลย (แท็บเล็ตไม่ต้องเปิดคีย์บอร์ด) หรือพิมพ์จากคีย์บอร์ด แล้วกด **เข้าสู่ระบบ**
2. **ตรวจชื่อ:** มุมซ้ายบนแสดงชื่อร้าน ใต้ชื่อร้านเป็นชื่อคุณและบทบาท เช่น "ครัวป้าแดง / น้องฝน · แคชเชียร์" ถ้าไม่ใช่ชื่อคุณ ให้ออกจากระบบแล้วเข้าใหม่
3. **ป้ายสถานะ:** จุดเขียว **ออนไลน์** มุมขวาบนแปลว่าเชื่อมต่อปกติ ถ้าเป็นจุดแดงกะพริบ **ขาดการเชื่อมต่อ** ข้อมูลบนจออาจไม่ใช่ล่าสุด
4. **ออกจากระบบ:** คอมพิวเตอร์กด **ออกจากระบบ** ล่างสุดของแถบซ้าย มือถือ/แท็บเล็ตกดไอคอนประตูมุมขวาบน ทุกครั้งที่ใช้เครื่องร่วมกับคนอื่น
5. **ใส่ PIN ผิดหลายครั้ง:** ระบบพักให้รอ 1 นาที เครื่องคอมพิวเตอร์ของร้านยังเข้าได้เสมอ

**แต่ละบทบาทเห็นอะไร**

| บทบาท | แท็บที่เห็น |
|---|---|
| ครัว | ครัว, เมนูหมด |
| แคชเชียร์ | ครัว, โต๊ะ & บิล, เมนูหมด, สรุปยอด |
| พนักงานเสิร์ฟ | ครัว, โต๊ะ & บิล (ไม่มีปุ่มรับเงิน), เมนูหมด |
| เจ้าของ | ครัว, โต๊ะ & บิล, เมนู, สรุปยอด, ตั้งค่า |

## 3. ครัว: จอครัว

<img src="screenshots/s03-kitchen.png" alt="จอครัว">

### เริ่มกะ
1. เปิดแท็บ **ครัว**
2. **แตะจอหนึ่งครั้ง** เพื่อเปิดเสียงเตือนออเดอร์ใหม่ (ถ้ามีป้ายเหลือง "เสียงแจ้งเตือนปิดอยู่ · แตะเพื่อเปิด" ให้แตะป้ายนั้น)
3. **ถ้ามีหลายจุดทำ:** กดปุ่มด้านบนเลือกจุดของตัวเอง (**ครัวร้อน / เครื่องดื่ม / ของหวาน** ตัวเลขข้างชื่อ = ออเดอร์ค้าง) หรือ **ทั้งหมด** เสียงจะดังเฉพาะออเดอร์ของจุดที่เลือก
4. **แท็บเล็ตติดผนังครัว:** กด **เต็มจอ** ซ่อนเมนูทั้งหมด ให้ออเดอร์ได้พื้นที่ทั้งจอ (ออกด้วยปุ่มเดิมหรือ Esc) และกดปุ่มพระจันทร์ (ล่างซ้าย หรือมุมขวาบนบนมือถือ) ถ้าอยากได้จอโหมดมืดไม่แสบตา

### เสียงแจ้งเตือน (ทุกบทบาท)

| เสียง | เมื่อไหร่ | ใครได้ยิน |
|---|---|---|
| ไล่ขึ้น 3 โน้ต | ออเดอร์ใหม่ | ครัว (เฉพาะจุดที่เลือก), เจ้าของ |
| ติ๊ด-ติ๊ด | ลูกค้ากดเรียกพนักงาน | แคชเชียร์, พนักงานเสิร์ฟ, เจ้าของ |
| ดิ๊ง-ด่อง | ลูกค้าขอเช็คบิล | แคชเชียร์, พนักงานเสิร์ฟ, เจ้าของ |
| กระดิ่ง | อาหารพร้อมเสิร์ฟ | แคชเชียร์, พนักงานเสิร์ฟ, เจ้าของ |

- **เตือนซ้ำทุก 1 นาที** ถ้ามีเรื่องค้าง: ออเดอร์ที่ยังไม่มีใครกด **เริ่มทำ** เกิน 2 นาที, ลูกค้าเรียก/ขอบิลแล้วยังไม่มีใครกด **รับทราบ** เกิน 1 นาที, อาหารพร้อมเสิร์ฟค้างเกิน 2 นาที จัดการแล้วเสียงหยุดเอง
- ข้อความบนจอขึ้นให้ทุกคนเห็นทุกเรื่อง เสียงดังเฉพาะเรื่องที่เป็นงานของคนนั้น
- **ถ้าไม่มีเสียง:** แตะจอหนึ่งครั้ง (หรือแตะป้ายเหลือง) · เปิดเสียงเครื่องให้ดัง · iPhone/iPad ปิด **สวิตช์เงียบ** ด้านข้าง (สวิตช์นี้ปิดเสียงจากเว็บด้วย) · ตั้งค่าเครื่องให้ **จอไม่ดับเอง** ระหว่างเปิดร้าน (จอดับ = ไม่มีเสียง) · อย่าปิดแท็บหน้าพนักงาน

### ทำออเดอร์
จอครัวแบ่งเป็น 3 ช่อง **ใหม่ → กำลังทำ → พร้อมเสิร์ฟ** (จอแคบเรียงจากบนลงล่าง) กดปุ่มบนการ์ดแล้วการ์ดย้ายไปช่องถัดไปเอง

1. ออเดอร์ใหม่ขึ้นในช่อง **ใหม่** บอกเลขโต๊ะ เวลาที่รอ (นาที) จำนวนในกรอบดำ ชื่ออาหาร **หมายเหตุ** (ป้ายสีเหลืองใต้ชื่ออาหาร) และข้อความจากลูกค้า
2. เริ่มทำแล้วกด **เริ่มทำ** ลูกค้าเห็น "กำลังทำ"
3. ทำเสร็จกด **ทำเสร็จ** หน้าร้านเห็นว่าโต๊ะนี้ "พร้อมเสิร์ฟ"
4. เสิร์ฟแล้วกด **เสิร์ฟแล้ว** (ครัวหรือหน้าร้านกดก็ได้) การ์ดหายจากจอ
5. ต้องการใบสั่งเป็นกระดาษ กด **พิมพ์** บนการ์ด (เครื่องพิมพ์ 80 มม. เลขโต๊ะตัวใหญ่ ไม่มีราคา)

### วัตถุดิบใกล้หมด
ถ้าร้านตั้งสต็อกไว้ จอครัวมีป้ายเหลือง **วัตถุดิบใกล้หมด: ไข่ไก่ เหลือ 8 ฟอง** แจ้งเจ้าของ/แคชเชียร์ให้สั่งของ ถ้าหมดจริงให้ตั้งเมนูที่ใช้วัตถุดิบนั้นเป็น **หมด** (ระบบไม่ตั้งให้เอง) ดูคงเหลือได้ที่ท้ายแท็บ **เมนูหมด**

### ข้อมูลช่วยครัว
- **ต้องทำรวม:** แถวบนสุดบอกยอดรวมของแต่ละเมนูที่ยังไม่ได้ทำ เช่น "4 ผัดกะเพราหมูสับ" ทำทีเดียวหลายจานได้
- **ออเดอร์ที่รอนาน:** เวลาบนการ์ดเปลี่ยนเป็นสีเหลือง (10 นาที) และแดง (15 นาที) ขอบการ์ดเปลี่ยนสี มีป้าย **เริ่มช้า** และ **รอนาน** และแถบบางๆ ใต้การ์ดยาวขึ้นตามเวลาที่รอ
- **เปลี่ยนสถานะได้ทางเดียว:** เดินหน้าได้ทีละขั้น ย้อนกลับไม่ได้ ถ้าสองเครื่องกดพร้อมกัน เครื่องหลังจะรีเฟรชให้เอง

### ของหมดระหว่างวัน
1. เปิดแท็บ **เมนูหมด** (เจ้าของใช้แท็บ **เมนู**)
2. ปิดสวิตช์ **มีขาย** ที่เมนูนั้น (เปลี่ยนเป็น **หมด** สีแดง) ลูกค้าเห็นว่าหมดภายใน 5 วินาที และเมนูที่อยู่ในรายการของลูกค้าจะถูกนำออกพร้อมแจ้ง
3. ของมาแล้วเปิดสวิตช์กลับเป็น **มีขาย**

> **ทางลัด:** กด **Ctrl+K** (หรือแตะไอคอนแว่นขยาย) พิมพ์ชื่อเมนู แล้วเลือก "ตั้งเป็นหมด: ..." ทำได้จากทุกแท็บ

> ครัวยกเลิกออเดอร์เองไม่ได้ ถ้าทำไม่ได้ (ของหมด / ลูกค้าเปลี่ยนใจ) ให้แจ้งแคชเชียร์

## 4. แคชเชียร์: โต๊ะ บิล และรับเงิน

### ผังโต๊ะ

<img src="screenshots/s05-tables-bill.png" alt="โต๊ะและบิล">

เปิดแท็บ **โต๊ะ & บิล** แต่ละโต๊ะบอกสถานะด้วยสีและข้อความ:

| ข้อความบนโต๊ะ | ความหมาย | ทำอะไร |
|---|---|---|
| ว่าง | ไม่มีออเดอร์ | — |
| เปิดโต๊ะแล้ว | พนักงานกดเปิดโต๊ะ (โหมดต้องเปิดโต๊ะก่อนสั่ง) ยังไม่มีออเดอร์ | ลูกค้าสแกน QR สั่งได้ |
| มีลูกค้า | มีออเดอร์ที่ยังไม่ปิดบิล | — |
| พร้อมเสิร์ฟ | ครัวทำเสร็จแล้ว | ยกอาหารไปเสิร์ฟ แล้วกด **เสิร์ฟแล้ว** |
| เรียกพนักงาน | ลูกค้ากดเรียก | ไปที่โต๊ะ แล้วกด **รับทราบ** |
| ขอเช็คบิล | ลูกค้าขอคิดเงิน | เปิดโต๊ะ แล้วทำตาม "ปิดบิล" ด้านล่าง |

แถวบนผังบอกจำนวนโต๊ะแต่ละสถานะ โต๊ะที่มีออเดอร์บอกยอดอาหารและนั่งมากี่นาที โต๊ะที่เรียก/ขอบิลมีวงแดงกระพริบรอบโต๊ะ

แตะโต๊ะเพื่อดูบิลของโต๊ะนั้น: บนคอมพิวเตอร์และแท็บเล็ตแนวนอน บิลอยู่ด้านขวาของผังโต๊ะ (ผังกับบิลเห็นพร้อมกัน) บนมือถือบิลอยู่ใต้ผังและเลื่อนลงไปให้เอง ในบิลมีรายการที่สั่งพร้อมสถานะ ใบแจ้งยอด และแถบรับเงินที่ติดอยู่ด้านล่างตลอด (ยอดชำระ ปุ่มรับเงินสด รับโอน/QR พิมพ์ใบแจ้งยอด)

ยังไม่ได้เลือกโต๊ะ ช่องบิลแสดง **ต้องดูแลตอนนี้**: โต๊ะที่เรียกพนักงาน ขอเช็คบิล หรือมีอาหารพร้อมเสิร์ฟ แตะเพื่อเปิดโต๊ะนั้นได้เลย

### เปิดโต๊ะ (ถ้าร้านเปิดโหมด "ต้องเปิดโต๊ะก่อนลูกค้าสั่ง")
1. พาลูกค้านั่งแล้ว แตะโต๊ะนั้นในผัง → กด **เปิดโต๊ะ** ลูกค้าสแกน QR สั่งได้ทันที โต๊ะแสดง "เปิดโต๊ะแล้ว"
2. ปิดบิลแล้วโต๊ะปิดเอง ไม่ต้องทำอะไรเพิ่ม
3. เปิดผิดโต๊ะ: แตะโต๊ะนั้น → **ปิดโต๊ะ** (ปิดได้เมื่อยังไม่มีออเดอร์)
4. ถ้าลูกค้าบอกว่า "สั่งไม่ได้ โต๊ะยังไม่เปิด" แปลว่ายังไม่ได้กดเปิดโต๊ะ

### สั่งแทนลูกค้า (ลูกค้าไม่มีมือถือ / สั่งปากเปล่า)
1. แตะโต๊ะ → กด **สั่งแทนลูกค้า** จะเปิดหน้าสั่งอาหารของโต๊ะนั้น
2. สั่งเหมือนลูกค้าทุกอย่าง ออเดอร์เข้าครัวพร้อมป้าย "พนักงานสั่ง"
3. สั่งได้แม้ร้านปิดรับออเดอร์ผ่าน QR อยู่

### ยกเลิกออเดอร์

<img src="screenshots/s04-void-dialog.png" alt="ยกเลิกออเดอร์">

1. ที่แท็บ **ครัว** กดปุ่ม **✕** (ยกเลิกออเดอร์) ข้างปุ่มสถานะบนการ์ดออเดอร์
2. **เลือกเหตุผล** (ต้องเลือก): ลูกค้าเปลี่ยนใจ / สั่งผิด/กดซ้ำ / ของหมด / รอนานเกินไป / อื่นๆ (ถ้าเลือก "อื่นๆ" ต้องพิมพ์รายละเอียด)
3. **ถ้าครัวเริ่มทำแล้ว:** แคชเชียร์ต้องให้ **เจ้าของใส่ PIN อนุมัติ** ในช่องที่ขึ้นมา (เจ้าของยกเลิกเองไม่ต้องใส่)
4. กด **ยืนยันยกเลิก** ทุกการยกเลิกบันทึกชื่อคนกด เหตุผล มูลค่า และคนอนุมัติ ไว้ในประวัติการแก้ไข
5. **ยกเลิกบางรายการ** (เช่น ลูกค้าสั่งข้าวผัด 3 จานแต่เอาแค่ 2): แท็บ **โต๊ะ & บิล** → แตะโต๊ะ → กด **ยกเลิก** ข้างรายการนั้น → ใส่ **จำนวน** ที่จะยกเลิก → เลือกเหตุผล → **ยืนยันยกเลิก** (กฎ PIN เจ้าของเหมือนยกเลิกทั้งใบ) ยอดบิลลดทันที

### ให้ส่วนลด
1. แท็บ **โต๊ะ & บิล** → แตะโต๊ะ → **ให้ส่วนลด** (อยู่ใต้ค่าบริการ/VAT)
2. เลือก **เปอร์เซ็นต์** หรือ **จำนวนเงิน** ใส่จำนวน ระบบแสดง "ลด ฿… · ยอดสุทธิ ฿…" ให้ตรวจก่อน
3. เลือกเหตุผล (ลูกค้าประจำ / โปรโมชัน / ชดเชยความผิดพลาด / พนักงาน/คนรู้จัก / อื่นๆ)
4. **แคชเชียร์:** ให้เจ้าของใส่ PIN อนุมัติ · เจ้าของให้เองไม่ต้องใส่
5. ส่วนลดหักจากค่าอาหารก่อน แล้วค่อยคิดค่าบริการ 10% และ VAT จากยอดหลังลด ใบแจ้งยอดและใบเสร็จมีบรรทัด **ส่วนลด** และ **ค่าอาหารหลังลด**
6. ลด % คิดจากยอดล่าสุดเสมอ (ลูกค้าสั่งเพิ่ม ส่วนลดเพิ่มตาม) · เอาออกได้ด้วย **เอาส่วนลดออก** · ถ้าอีกเครื่องแก้ส่วนลดระหว่างที่กำลังรับเงิน ระบบไม่ยอมปิดบิลจนกว่าจะเห็นยอดใหม่
7. รวมโต๊ะที่มีส่วนลดไม่ได้ ให้เอาส่วนลดออกก่อน รวมโต๊ะแล้วค่อยให้ใหม่

### สั่งกลับบ้าน / เดลิเวอรี (เลขคิว)
1. แท็บ **โต๊ะ & บิล** → ส่วน **กลับบ้าน / เดลิเวอรี** → **+ สั่งกลับบ้าน** หรือ **+ เดลิเวอรี**
2. ใส่ชื่อลูกค้าหรือเลขออเดอร์ของแอป (ไม่บังคับ) → **ขอเลขคิว** ได้ **คิว 1, 2, 3 …** (เริ่ม 1 ใหม่ทุกวัน)
3. กด **สั่งแทนลูกค้า** เลือกเมนูและส่งเข้าครัวเหมือนสั่งให้โต๊ะ (ราคาเท่าหน้าร้าน) จอครัวบอก **คิว n · กลับบ้าน · ชื่อ**
4. รับเงิน: ค่าบริการ **ปิด** เป็นค่าเริ่มต้น · ลูกค้าจ่ายผ่านแอปเดลิเวอรี ใช้ **แบ่งจ่าย / อื่นๆ** ใส่ชื่อแอปในช่อง "อื่นๆ"
5. ลูกค้าเปลี่ยนใจนั่งทานที่ร้าน: **ย้ายไปนั่งโต๊ะ** · ขอคิวแล้วไม่สั่ง: **ยกเลิกคิว**

### ย้ายโต๊ะ / รวมโต๊ะ
1. แท็บ **โต๊ะ & บิล** → แตะโต๊ะที่จะย้าย → **ย้าย/รวมโต๊ะ**
2. เลือกโต๊ะปลายทาง → **ย้ายโต๊ะ** ออเดอร์ การเรียก และสถานะเปิดโต๊ะย้ายไปทั้งหมด
3. ถ้าโต๊ะปลายทางมีออเดอร์อยู่ ระบบถามก่อนว่าจะ **รวมเป็นบิลเดียว** (รวมแล้วแยกกลับไม่ได้ ถ้าจะจ่ายแยกให้ปิดบิลโต๊ะเดิมก่อน)
4. ลูกค้าที่ย้ายโต๊ะ ให้สแกน QR ของโต๊ะใหม่เพื่อสั่งเพิ่ม · พนักงานเสิร์ฟย้ายโต๊ะได้ (ไม่เกี่ยวกับเงิน)

### ปิดบิล (รับเงิน)
1. แตะโต๊ะที่จะคิดเงิน ตรวจรายการบน **ใบแจ้งยอด**
2. เปิด/ปิด **ค่าบริการ 10%** และ **VAT 7%** ได้ตามที่ร้านคิดจริง
3. ถ้ามีป้ายเหลือง "ยังมี N รายการที่ยังไม่ได้เสิร์ฟ" ให้ตรวจกับลูกค้าก่อน ปิดบิลแล้วรายการเหล่านั้นจะหายจากจอครัว
4. ถ้าลูกค้าขอดูยอดก่อน กด **พิมพ์ใบแจ้งยอด** (มี QR PromptPay ตามยอดจริงให้ลูกค้าสแกนจ่าย)

**รับเงินสด**

<img src="screenshots/s06-cash-change.png" width="560" alt="รับเงินสด">

5. กด **รับเงินสด** ช่อง **รับเงินมา (บาท)** จะขึ้นมา
6. พิมพ์จำนวนที่รับ หรือกดปุ่มลัดใต้ช่อง (ยอดพอดี และยอดที่ปัดขึ้น เช่น ฿583 / ฿600 / ฿1,000) ระบบแสดง **ทอน ฿…** ตัวใหญ่
7. กด **ยืนยัน ฿…** (หรือกด Enter) ถ้าเงินไม่พอกดไม่ได้

**รับโอน / สแกน QR**

5. ให้ลูกค้าสแกน QR บนใบแจ้งยอด **ตรวจว่าเงินเข้าบัญชีแล้ว**
6. กด **รับโอน / QR** แล้วกด **ยืนยัน** อีกครั้ง

**รับบัตร**

5. รูดบัตรที่เครื่องรูดบัตรของร้านจนสำเร็จ แล้วกด **รับบัตร** → **ยืนยัน** (ระบบไม่ได้ต่อกับเครื่องรูดบัตร ตอนปิดร้านเทียบยอดบัตรกับสลิปสรุปของเครื่อง)

**แบ่งจ่าย / ช่องทางอื่น** (เช่น เงินสด 200 + โอน 150, หรือจ่ายผ่านแอปเดลิเวอรี/คูปอง)

5. กด **แบ่งจ่าย / อื่นๆ** ใส่ยอดของแต่ละช่องทาง (เงินสด / โอน / QR / บัตร / อื่นๆ) ถ้ามี "อื่นๆ" ใส่ **ชื่อช่องทางอื่น** ด้วย
6. ยอดทุกช่องรวมกันต้องเท่ายอดบิลพอดี (ระบบบอกยอดที่ยังขาด/เกิน) ถ้ามีเงินสดและต้องทอน ใส่ **รับเงินสดมา**
7. กด **ยืนยัน** ใบเสร็จแสดงทุกช่องทางและเงินทอน

**หลังปิดบิล**

<img src="screenshots/s07-receipt-paid.png" width="560" alt="ใบเสร็จ">

8. ได้ **ใบเสร็จรับเงิน** เลขที่ต่อเนื่อง กด **พิมพ์ใบเสร็จ** (เครื่องพิมพ์ 80 มม.) แล้วกด **เสร็จ**
9. ถ้าลูกค้าสั่งเพิ่มระหว่างที่กำลังคิดเงิน ระบบไม่ยอมปิดบิลด้วยยอดเก่า ให้ตรวจยอดใหม่แล้วกดรับเงินอีกครั้ง

### พิมพ์ใบเสร็จย้อนหลัง
แท็บ **สรุปยอด** → ส่วน **บิลวันนี้** → **ดูใบเสร็จ** → **พิมพ์ซ้ำ**

### ตั้งเครื่องพิมพ์ใบเสร็จ (ทำครั้งเดียว)
ระบบพิมพ์ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์ ใบเสร็จกว้าง 72 มม. พอดีเครื่องพิมพ์ความร้อน (thermal) กระดาษ 80 มม. ใบยาวพิมพ์ต่อเนื่องตามจำนวนรายการ

**แบบที่แนะนำ: เครื่องพิมพ์ต่อกับคอมเครื่องร้าน (USB หรือ LAN)**
1. ติดตั้งไดรเวอร์ของเครื่องพิมพ์ (Xprinter, Epson TM, Gprinter ฯลฯ) ใน Windows → **การตั้งค่า → เครื่องพิมพ์** → เลือกเครื่อง → **การกำหนดลักษณะการพิมพ์** ตั้งกระดาษเป็น **80 มม. (Receipt / Roll)**
2. กด **พิมพ์ใบแจ้งยอด** ครั้งแรก ในหน้าต่างพิมพ์ตั้งค่าเหล่านี้ (เบราว์เซอร์จำไว้ให้):
   - **เครื่องพิมพ์:** เครื่องพิมพ์ใบเสร็จ
   - **ระยะขอบ (Margins):** ไม่มี (None)
   - **ขนาด (Scale):** ค่าเริ่มต้น / 100%
   - **ส่วนหัวและส่วนท้าย (Headers and footers):** ปิด ไม่อย่างนั้นวันที่และที่อยู่เว็บจะพิมพ์ติดมา
   - **กราฟิกพื้นหลัง:** ไม่ต้องเปิด
3. ลองพิมพ์ใบแจ้งยอดโต๊ะที่มีหลายรายการ ดูว่าครบถึง QR และ "ขอบคุณที่ใช้บริการ"
4. **กระดาษ 58 มม.:** ในหน้าต่างพิมพ์ตั้ง **Scale** ประมาณ 75–80%

**พิมพ์จากมือถือ/แท็บเล็ต**
- **iPhone/iPad:** ได้เฉพาะเครื่องพิมพ์ที่รองรับ AirPrint (เครื่องพิมพ์ใบเสร็จส่วนใหญ่ไม่รองรับ)
- **Android:** ได้ถ้าเครื่องพิมพ์มีบริการพิมพ์ของ Android (เช่น Mopria หรือแอปของยี่ห้อนั้น) เครื่องพิมพ์บลูทูธราคาถูกต้องใช้แอปช่วยพิมพ์ เช่น RawBT
- ถ้าไม่สะดวก ให้แคชเชียร์ปิดบิลที่คอมเครื่องร้านที่ต่อเครื่องพิมพ์ไว้ ส่วนพนักงานบนมือถือใช้เปิดใบแจ้งยอดให้ลูกค้าสแกนจ่ายบนจอได้เลย

> ยังไม่มี: พิมพ์อัตโนมัติทันทีที่ปิดบิล (เบราว์เซอร์บังคับให้กดยืนยันในหน้าต่างพิมพ์ทุกครั้ง) และพิมพ์ใบสั่งอาหารในครัว

## 5. เจ้าของ: จัดการเมนู

<img src="screenshots/s08-menu-manager.png" alt="จัดการเมนู">

### เพิ่มหรือแก้เมนู

<img src="screenshots/s09-menu-editor.png" width="560" alt="แก้เมนู">

1. แท็บ **เมนู** → กด **เพิ่มเมนูใหม่** หรือกดปุ่มดินสอ (แก้ไข) ที่เมนูเดิม หน้าแก้ไขขึ้นบนสุดของรายการเมนู
2. ใส่ **ชื่อ**, **ราคา** (มีทศนิยมได้ เช่น 49.50), **หมวด**, **จุดที่ทำ** (ครัวร้อน/เครื่องดื่ม/ของหวาน: เลือกให้ถูก ออเดอร์จะไปขึ้นจอจุดนั้น) และ **คำอธิบาย** (ไม่บังคับ ลูกค้าเห็นในหน้ารายละเอียด)
3. **รูป:** กด **เลือกรูปอาหาร** ถ่ายจากมือถือหรือเลือกไฟล์ได้เลย ระบบย่อรูปให้เอง จะเอาออกกด **เอารูปออก**
4. **เมนูแนะนำ:** เปิดสวิตช์ **เมนูแนะนำ** เมนูนั้นจะขึ้นแถวบนสุดของหน้าลูกค้าพร้อมป้าย "แนะนำ" (เลือกเมนูเด่นของร้าน 3–6 อย่างกำลังดี ถ้าไม่เลือกเลย ระบบใช้เมนูขายดีจากยอดขายจริงแทน)
5. กด **บันทึก** ลูกค้าที่เปิดหน้าเมนูอยู่เห็นของใหม่ภายใน 5 วินาที

- **แก้ราคา:** มีผลกับออเดอร์ใหม่เท่านั้น ออเดอร์ที่สั่งไปแล้วคิดราคาเดิม
- **สองเครื่องแก้เมนูเดียวกันพร้อมกัน:** ระบบไม่ให้บันทึกทับกัน เครื่องหลังจะได้ข้อความให้เปิดใหม่

### ซ่อน / หมด / ลบ: ใช้ตัวไหน

| สถานการณ์ | ใช้ | ผล |
|---|---|---|
| ของหมดวันนี้ พรุ่งนี้มีขาย | ปิดสวิตช์ **มีขาย** (เป็น **หมด**) | ลูกค้าเห็นเมนูแต่สั่งไม่ได้ |
| เมนูตามฤดูกาล / พักขายนานๆ | **แก้ไข** → เปิดสวิตช์ **ซ่อนจากหน้าลูกค้า** | ลูกค้าไม่เห็นเลย ข้อมูลยังอยู่ เปิดกลับได้ |
| เลิกขายถาวร | **แก้ไข** → **ลบเมนู** → ยืนยัน | ลบเมนูและรูปถาวร ยอดขายเก่ายังอยู่ |

### หมวดหมู่
- **เพิ่มหมวด:** พิมพ์ชื่อในช่อง "ชื่อหมวดใหม่" แล้วกด **เพิ่ม**
- **เปลี่ยนชื่อ:** กดปุ่มดินสอ พิมพ์ชื่อใหม่ แล้วกด **บันทึก**
- **เลื่อนลำดับ:** กดลูกศรขึ้น / ลง ลำดับนี้คือลำดับที่ลูกค้าเห็น
- **ลบ:** กดปุ่มถังขยะ แล้วยืนยัน ลบได้เฉพาะหมวดที่ไม่มีเมนูเหลือ
- **ดูเฉพาะหมวด:** แตะชื่อหมวดในแถวเหนือรายการเมนู (**ทุกหมวด** = ดูทั้งหมด)
- ส่วนจัดการหมวดและตัวเลือกหมายเหตุอยู่ด้านขวาของรายการเมนู (มือถืออยู่ท้ายรายการ)

### ตัวเลือกหมายเหตุ
แก้ในช่อง **ตัวเลือกหมายเหตุ** คั่นด้วยเครื่องหมายจุลภาค (,) เช่น `ไม่เผ็ด, เผ็ดน้อย, ไม่ใส่ผัก` แล้วกด **บันทึกตัวเลือก** ลูกค้ากดเลือกได้เฉพาะตัวเลือกในรายการนี้

### สต็อกวัตถุดิบและสูตร (แท็บ สต็อก)
**ตั้งครั้งแรก**
1. **+ เพิ่มวัตถุดิบ**: ชื่อ หน่วย (กก. กรัม ฟอง ขวด …) และ **แจ้งเตือนเมื่อเหลือไม่เกิน** (0 = ไม่เตือน)
2. กด **รับเข้า** ใส่จำนวนที่มีอยู่ตอนนี้และราคาทุนต่อหน่วย
3. ส่วน **สูตรต่อเมนู** → **ใส่สูตร** ข้างเมนู → เลือกวัตถุดิบและปริมาณ **ต่อ 1 จาน** (เช่น ข้าวสาร 0.2 กก. ไข่ไก่ 1 ฟอง) หน้าต่างบอกทุนต่อจานและกำไร %
4. จากนั้นทุกออเดอร์ที่ส่งเข้าครัว ระบบตัดวัตถุดิบตามสูตรเอง ยกเลิกออเดอร์แล้วคืนให้

**ใช้ทุกวัน** (แคชเชียร์ทำได้ที่ท้ายแท็บ **เมนูหมด**)
- ของเข้าร้าน: **รับเข้า** พร้อมราคาทุน (ราคาเปลี่ยน ระบบคิดทุนเฉลี่ยให้)
- เอาไปใช้นอกสูตร (เช่น อาหารพนักงาน): **เบิกใช้**
- เน่า หก หมดอายุ: **ของเสีย** (ต้องใส่เหตุผล)
- **ตรวจนับ** (แนะนำทุกสัปดาห์): ใส่ยอดที่นับได้จริง ระบบบันทึกส่วนต่าง ถ้ามีออเดอร์ตัดสต็อกระหว่างนับ ระบบให้ตรวจยอดใหม่ก่อน
- ป้าย **ใกล้หมด** / **หมด** ในตาราง = ถึงเวลาสั่งของ (ของไม่พอระบบยังรับออเดอร์ ยอดติดลบให้ตรวจ)

**ต้นทุนและกำไร:** แผงรายงานในแท็บสรุปยอดบอก **ต้นทุนวัตถุดิบ** และ **กำไรขั้นต้น** (ค่าอาหารหลังส่วนลด − ทุน) คิดเฉพาะบิลที่มีเมนูที่ใส่สูตรแล้ว CSV มีคอลัมน์ต้นทุนวัตถุดิบ

### เปิดกะ / ปิดกะ (นับเงินในลิ้นชัก)
ไม่บังคับ แต่ช่วยจับเงินขาด/เกินได้ทุกกะ แคชเชียร์และเจ้าของทำได้
1. เริ่มขาย: แท็บ **สรุปยอด** → แผง **กะ / เงินในลิ้นชัก** → ใส่ **เงินทอนตั้งต้น** (ไม่มีใส่ 0) → **เปิดกะ**
2. ระหว่างกะ แผงบอก **เงินที่ควรมีในลิ้นชัก** = เงินทอนตั้งต้น + เงินสดที่รับ (หักเงินทอนแล้ว) โอน/บัตรไม่นับ
3. ปิดกะ: นับเงินในลิ้นชักทั้งหมด → ใส่ **นับเงินได้จริง** (และหมายเหตุ เช่น จ่ายค่าน้ำแข็ง) → **ปิดกะ** → ระบบบอก **เงินขาด / เงินเกิน / ตรงพอดี** ก่อนยืนยัน
4. ประวัติกะ (ใครเปิด/ปิด ควรมี นับได้ ขาด/เกิน) อยู่ใต้แผงเดียวกัน

### รายงานวันนี้ / เดือนนี้ / ปีนี้
แผง **รายงาน** ในแท็บ **สรุปยอด** (เจ้าของกดเลือก **วันนี้ / เดือนนี้ / ปีนี้** · แคชเชียร์เห็นเฉพาะวันนี้)
- ยอดขาย จำนวนบิล ค่าเฉลี่ย ยอดแยกตามช่องทาง และจำนวน/มูลค่าที่ยกเลิก
- กราฟยอดรายชั่วโมง (วันนี้) รายวัน (เดือนนี้) รายเดือน (ปีนี้) · ยอด **แยกตามคนรับเงิน**
- **ขายดี** และ **ขายไม่ดี** (จำนวนจาน) และ **ไม่มีใครสั่ง** = เมนูที่ยังขายอยู่แต่ไม่มีใครสั่งเลยในช่วงนั้น ใช้ตัดสินใจปรับเมนู
- **รายการยกเลิก** แยกตามเหตุผลและคนที่กดยกเลิก ถ้าคนใดคนหนึ่งยกเลิกบ่อยผิดปกติ ดูรายละเอียดในประวัติการแก้ไข
- เดือนนี้/ปีนี้ไม่อัปเดตเองทุกออเดอร์ (อ่านข้อมูลทั้งเดือน) กด **โหลดใหม่** เพื่อดูตัวเลขล่าสุด

### อ่านหน้าสรุปยอด

| ส่วน | ใช้ทำอะไร |
|---|---|
| **ยอดขายวันนี้** | ยอดรวมทุกบิลที่ปิดแล้ว จำนวนบิล และค่าเฉลี่ยต่อบิล |
| **เงินสด** | เทียบกับเงินในลิ้นชักตอนปิดร้าน |
| **โอน / QR** | เทียบกับยอดเข้าบัญชีธนาคาร |
| **รอชำระ** | โต๊ะที่ยังไม่ปิดบิล (ปิดร้านแล้วควรเป็น 0) |
| **เมนูขายดีวันนี้** / **ยอดขาย 7 วันล่าสุด** | ใช้วางแผนของและดูแนวโน้ม |
| **ประวัติการแก้ไขวันนี้** | ใครยกเลิกออเดอร์ (เหตุผล มูลค่า คนอนุมัติ) แก้ราคา เปลี่ยน PromptPay เพิ่มพนักงาน กู้คืน จากเครื่องไหน |
| **บิลวันนี้** | ดู/พิมพ์ใบเสร็จย้อนหลัง |

### ปิดร้าน (ทำทุกวัน ประมาณ 5 นาที)
1. แท็บ **ตั้งค่า** → **การรับออเดอร์** → ปิดสวิตช์ **รับออเดอร์ผ่าน QR** → **บันทึกการตั้งค่า** (พนักงานยังสั่งแทนได้)
2. ตรวจว่า **รอชำระ** เป็น 0 ถ้าไม่ใช่ ให้ปิดบิลโต๊ะที่เหลือ
3. นับเงินในลิ้นชัก แล้ว **ปิดกะ** (ถ้าเปิดกะไว้) ระบบบอกขาด/เกิน · ถ้าไม่ได้เปิดกะ นับเงิน (หักเงินทอนตั้งต้น) เทียบกับ **เงินสด** · ยอดบัตรเทียบกับสลิปสรุปของเครื่องรูดบัตร
4. ตรวจยอดเข้าบัญชีเทียบกับ **โอน / QR**
5. ถ้ายอดไม่ตรง ดู **ประวัติการแก้ไขวันนี้** โดยเฉพาะรายการยกเลิกออเดอร์
6. ถ้ามีป้าย **ตรวจพบการแก้ไข log** แปลว่ามีคนแก้ไฟล์บันทึกนอกระบบ ให้ตรวจสอบทันที
7. เปิดร้านวันถัดไป: เปิด **รับออเดอร์ผ่าน QR** กลับ

### ส่งยอดให้บัญชี (สิ้นเดือน)
กด **ดาวน์โหลดยอดขายเดือนนี้ (CSV)** เปิดด้วย Excel ได้ ภาษาไทยไม่เพี้ยน หนึ่งบรรทัดต่อหนึ่งบิล มีคอลัมน์ยอดแยกเงินสด/โอน/บัตร/อื่นๆ และคนรับเงิน
ถ้าต้องการเก็บประวัติการแก้ไขไว้เอง กด **ดาวน์โหลด log เดือนนี้**

## 7. เจ้าของ: ตั้งค่าร้าน

### ข้อมูลร้าน

<img src="screenshots/s11-settings.png" width="700" alt="ตั้งค่า">

แท็บ **ตั้งค่า** แบ่งเป็นหัวข้อ กดชื่อหัวข้อในเมนูย่อย (คอมพิวเตอร์อยู่ด้านซ้าย มือถืออยู่บนสุด เลื่อนซ้ายขวาได้) เพื่อไปที่หัวข้อนั้น: **ข้อมูลร้าน · การรับเงิน · การรับออเดอร์ · ลิงก์ร้าน · หน้าตาร้าน · พนักงาน · QR ประจำโต๊ะ · สำรองข้อมูล**

1. **ข้อมูลร้าน:** **ชื่อร้าน**, **เบอร์โทรร้าน**, **ที่อยู่ร้าน**, **เลขประจำตัวผู้เสียภาษี** (ถ้ามี), **ข้อความท้ายใบเสร็จ** และ **คำโปรยใต้ชื่อร้าน** (ไม่บังคับ) เช่น "อาหารไทยรสชาติต้นตำรับ ปรุงสดใหม่ทุกวัน" ขึ้นใต้ชื่อร้านบนการ์ดหน้าปกของหน้าลูกค้า
2. **การรับเงิน:** **PromptPay** (เบอร์มือถือ 10 หลัก หรือเลขบัตร 13 หลัก) รูป QR รับเงินของร้าน (ด้านล่าง) และสวิตช์ **ค่าบริการ 10% เป็นค่าเริ่มต้น**, **VAT 7% เป็นค่าเริ่มต้น**
3. **การรับออเดอร์:** สวิตช์ **รับออเดอร์ผ่าน QR** ส่วนกันออเดอร์ปลอม (ด้านล่าง) **จำนวนโต๊ะ** และ **ที่อยู่เว็บที่ใส่ใน QR** ปล่อยว่างให้ระบบหาเอง ถ้าระบบเตือนว่าเป็น localhost ให้ใส่ `http://<IP เครื่องร้าน>:3000`
4. ช่องในหัวข้อ 1–4 บันทึกพร้อมกันด้วยปุ่ม **บันทึกการตั้งค่า** ที่แถบลอยด้านล่าง ถ้าแก้แล้วยังไม่บันทึก แถบจะขึ้นสีเหลือง "มีการแก้ไขที่ยังไม่ได้บันทึก"
5. **ลิงก์ร้าน (ติดตามร้าน และแชร์ร้าน):** ใส่ลิงก์ หรือแค่ชื่อบัญชี เช่น `@ครัวป้าแดง` ในช่อง **เพจ Facebook**, **Instagram**, **LINE Official Account**, **TikTok** ช่องที่ว่างไว้ไม่ขึ้นในหน้าลูกค้า
   - **ลิงก์ที่ลูกค้ากด "แชร์ร้านนี้":** ใส่ลิงก์ Google Maps ของร้าน เพจ หรือเว็บร้าน ลูกค้ากดแชร์แล้วส่งลิงก์นี้ให้เพื่อน (ไม่ส่ง QR ของโต๊ะ เพราะคนที่ได้ไปจะสั่งอาหารเข้าโต๊ะนั้นได้) ปล่อยว่าง = ไม่มีปุ่มแชร์
   - ใส่ลิงก์ผิดช่อง (เช่น ลิงก์ Facebook ในช่อง TikTok) ระบบไม่บันทึกและบอกว่าผิดช่องไหน
   - เปลี่ยนลิงก์ต้องใส่ PIN ยืนยันอีกครั้ง (กันคนแอบเปลี่ยนให้ลูกค้าไปเว็บอื่น)
6. กด **บันทึกการตั้งค่า** ถ้ามีช่องไหนผิด จะไม่มีอะไรถูกบันทึกเลย แก้ช่องนั้นแล้วกดใหม่

**รูป QR รับเงินของร้าน (ไม่บังคับ):** ถ้ามี QR จากแอปธนาคาร หรือ QR ร้านค้า (แม่มณี, K SHOP ฯลฯ) กด **อัปโหลดรูป QR** แล้วยืนยัน PIN ใบแจ้งยอดจะใช้รูปนี้แทน QR ที่สร้างจากเบอร์ และบอกยอดตัวใหญ่ให้ลูกค้าพิมพ์เอง (QR จากเบอร์ใส่ยอดให้อัตโนมัติ) ครอปรูปให้เห็นแค่ QR จะสแกนง่ายขึ้น จะกลับไปใช้ QR จากเบอร์กด **เลิกใช้รูปนี้**

> เปลี่ยนเบอร์ PromptPay หรือรูป QR แล้ว ให้ลองจ่าย 1 บาทจาก QR บนใบแจ้งยอดทุกครั้ง การเปลี่ยนนี้ถูกบันทึกในประวัติการแก้ไข

ในแท็บ **ตั้งค่า** หัวข้อ **การรับออเดอร์** แล้วกด **บันทึกการตั้งค่า**
- **ต้องเปิดโต๊ะก่อนลูกค้าสั่ง:** แนะนำให้เปิด QR ของโต๊ะว่างสั่งไม่ได้จนกว่าพนักงานกดเปิดโต๊ะ (ดูส่วน 4) กันคนถ่ายรูป QR ไปแกล้งสั่ง
- **ปิดรับ QR อัตโนมัตินอกเวลา:** เปิดแล้วใส่เวลา **รับออเดอร์ตั้งแต่ … ถึง …** ร้านที่ปิดหลังเที่ยงคืนใส่ได้ เช่น 17:00 ถึง 02:00 นอกเวลาลูกค้าสั่งไม่ได้ พนักงานยังสั่งแทนได้
- **รูป QR โต๊ะไหนหลุดออกไป หรือสงสัยว่ามีคนแกล้งสั่ง:** ไปที่ **QR ประจำโต๊ะ** → กด **เปลี่ยนรหัส** บนการ์ดโต๊ะนั้น → ยืนยัน → พิมพ์แผ่นใหม่ไปติดแทน (โต๊ะอื่นไม่กระทบ)

### ใส่ PIN ซ้ำก่อนทำเรื่องสำคัญ
ก่อนเปลี่ยนเบอร์ PromptPay, เปลี่ยนที่อยู่ใน QR, เพิ่ม/แก้/ปิดบัญชีพนักงาน, ดาวน์โหลดไฟล์สำรอง, กู้คืน, เปลี่ยนลิงก์โซเชียล/ลิงก์แชร์, อัปโหลด/เลิกใช้รูป QR รับเงิน หรือเปลี่ยนรหัส QR ถ้าเข้าสู่ระบบมานานกว่า 5 นาที จะขึ้นหน้าต่าง **ใส่ PIN ของคุณอีกครั้ง** ใส่ PIN แล้วกด **ยืนยัน** ระบบทำรายการเดิมต่อให้เอง ไม่ต้องกดซ้ำ
- เจ้าของต้องเข้าสู่ระบบใหม่ทุก 12 ชั่วโมง (บทบาทอื่นไม่ต้อง)
- ถ้ามีคนขโมยการเข้าสู่ระบบไปได้ (เช่น ใช้เครื่องที่ลืมออกจากระบบ) ก็ยังทำเรื่องสำคัญเหล่านี้ไม่ได้ถ้าไม่รู้ PIN

### เพิ่มหรือลบโต๊ะ

<img src="screenshots/s18-confirm-delete.png" width="560" alt="ลบโต๊ะ">

- **เพิ่มโต๊ะ:** แท็บ **โต๊ะ & บิล** → ช่อง **+ เพิ่มโต๊ะ** ท้ายผัง (สูงสุด 60) แล้วพิมพ์ QR ของโต๊ะใหม่
- **ลบโต๊ะ:** ช่อง **− ลบโต๊ะ N** ท้ายผัง → อ่านหน้าต่างยืนยัน → **ลบโต๊ะ N**
  - ลบได้จากเลขสุดท้ายเท่านั้น และโต๊ะนั้นต้องไม่มีออเดอร์หรือการเรียกค้าง
  - QR ของโต๊ะที่ลบจะสั่งไม่ได้ ควรเก็บแผ่น QR ออก ถ้าเพิ่มโต๊ะกลับมา QR แผ่นเดิมใช้ได้อีก

### หน้าตาร้าน: โลโก้ ภาพพื้นหลัง และสีปุ่ม

<img src="screenshots/s12-theme.png" width="700" alt="หน้าตาร้าน">

1. **โลโก้:** กด **เลือกรูปโลโก้** (PNG พื้นใส หรือ JPG สี่เหลี่ยมจัตุรัส) อัปโหลดทันที จะเปลี่ยนกด **เปลี่ยนโลโก้** จะเอาออกกด **เอาโลโก้ออก** แล้วยืนยัน
2. **ภาพพื้นหลังหน้าลูกค้า:** กด **เลือกภาพพื้นหลัง** ใช้ภาพแนวนอน เช่น หน้าร้าน บรรยากาศร้าน หรืออาหารเด่น ระบบย่อให้เอง ภาพแสดงเต็มที่หน้าปกด้านบนของหน้าลูกค้า และจางๆ เป็นพื้นหลังทั้งหน้า (ตัวหนังสือยังอ่านชัด) หน้าใส่รหัสพนักงานก็ใช้ภาพนี้ จะเอาออกกด **เอาภาพพื้นหลังออก** แล้วยืนยัน ไม่มีภาพ ระบบใช้สีร้านไล่สีแทน
3. **โทนสีหน้าลูกค้า:** **มืด** (ค่าเริ่มต้น พื้นเข้มแบบร้านอาหารยามค่ำ รูปอาหารเด่น) / **สว่าง** (พื้นขาว) / **ตามเครื่องลูกค้า** กดแล้วมีผลทันที (หน้าพนักงานแต่ละเครื่องเลือกโหมดของตัวเองได้ที่ปุ่ม จอ / ดวงอาทิตย์ / พระจันทร์ ล่างซ้าย หรือมุมขวาบนบนมือถือ)
4. **สีปุ่ม:** กดชุดสี (มะนาว, ส้มพริก, แดงพริก …) หรือ **เลือกสีเอง** ดูผลในกล่อง **ตัวอย่าง** แล้วกด **บันทึกสี** จะยกเลิกกด **ยกเลิก**
5. ถ้าขึ้นว่า "สีนี้อ่อนเกินไป" ให้เลือกสีที่เข้มขึ้น สีขาวหรือเกือบขาวจะทำให้ปุ่มกลืนกับพื้น
6. หน้าลูกค้าที่เปิดอยู่เปลี่ยนสี โทน โลโก้ และภาพพื้นหลังตามภายใน 5 วินาที
7. **ป้าย "ขายดี":** ขึ้นเองบน 3 เมนูที่ขายได้มากที่สุดใน 7 วัน (อย่างน้อย 3 จาน) ไม่ต้องตั้งค่า **ที่อยู่และเบอร์โทร** ในข้อมูลร้านจะขึ้นท้ายหน้าลูกค้า กดโทรได้

### พนักงาน

<img src="screenshots/s13-staff.png" width="700" alt="พนักงาน">

1. **เพิ่มพนักงาน:** กด **เพิ่มพนักงาน** ใส่ชื่อ เลือกบทบาท (แคชเชียร์ / พนักงานเสิร์ฟ / ครัว / เจ้าของ) · **พนักงานเสิร์ฟ** สั่งอาหารแทนลูกค้า เห็นโต๊ะที่เรียก เปิดโต๊ะ เสิร์ฟได้ แต่รับเงิน ยกเลิกออเดอร์ และดูยอดขายไม่ได้ และตั้ง PIN 6–8 หลักที่ไม่ซ้ำกับใคร แล้วบอก PIN ให้พนักงานคนนั้นคนเดียว
2. **เปลี่ยน PIN หรือบทบาท:** กด **แก้ไข** ที่แถวของคนนั้น เครื่องที่คนนั้นเข้าอยู่จะหลุด ต้องเข้าใหม่ด้วย PIN ใหม่
3. **พนักงานลาออก:** กด **ปิดบัญชี** แล้วยืนยัน เข้าระบบไม่ได้ทันที ประวัติการทำงานยังอยู่
4. **ทำมือถือหาย / ลืมออกจากระบบ:** กด **ออกจากระบบทุกเครื่อง** ของคนนั้น
5. **บัญชี "เจ้าของร้าน"** ใช้ PIN ที่ตั้งตอนเปิดโปรแกรม (`STAFF_PIN`) ลบไม่ได้ เปลี่ยน PIN ได้ด้วยการเปลี่ยนค่าในไฟล์ที่ใช้เปิดโปรแกรม

### สำรองและกู้คืนข้อมูล

<img src="screenshots/s14-backup.png" width="700" alt="สำรองข้อมูล">

- **อัตโนมัติ:** ระบบสำรองทุก 4 ชั่วโมงเมื่อมีข้อมูลเปลี่ยน ดูได้ที่กล่อง **สำรองล่าสุด**
- **สำรองเอง:** กด **สำรองข้อมูลตอนนี้** เช่น ก่อนแก้เมนูครั้งใหญ่
- **เก็บนอกเครื่อง:** กด **ดาวน์โหลด** ไปเก็บใน Google Drive หรือแฟลชไดรฟ์ อย่างน้อยสัปดาห์ละครั้ง (ถ้าตั้ง `BACKUP_DIR` ไว้ ระบบคัดลอกให้เอง และหน้าจอจะบอกว่าคัดลอกสำเร็จ)
- **กู้คืน:**
  1. กด **เลือกไฟล์สำรอง (.json.gz หรือ .json)** ตรวจรายละเอียดไฟล์ที่ขึ้นมา
  2. กด **กู้คืนจากไฟล์นี้** แล้ว **กู้คืนข้อมูล** ในหน้าต่างยืนยัน
  3. ระบบสำรองข้อมูลปัจจุบันไว้ให้ก่อน ระหว่างกู้คืนลูกค้าสั่งไม่ได้ไม่กี่วินาที และทุกเครื่องต้องเข้าสู่ระบบใหม่
- **ไฟล์สำรองเป็นความลับ:** มีรหัส QR ทุกโต๊ะและข้อมูลร้าน อย่าแชร์

### QR ติดโต๊ะ

<img src="screenshots/s15-qr-sheet.png" width="700" alt="QR ประจำโต๊ะ">

1. **ลองก่อนพิมพ์จริง:** สแกน QR โต๊ะ 1 ด้วยมือถือที่ต่อ WiFi ร้าน ต้องเปิดหน้าเมนูได้
2. **เลือกวิธี:**
   - **พิมพ์ QR ทุกโต๊ะ (A4 หน้าละ 6 ใบ):** เลือกเครื่องพิมพ์ หรือ "บันทึกเป็น PDF" แล้วตัดตามเส้นประ
   - **พิมพ์** บนการ์ดโต๊ะ: พิมพ์ใบเดียวขนาดใหญ่ (ใช้ตอน QR โต๊ะไหนเสีย)
   - **PNG** บนการ์ดโต๊ะ: ดาวน์โหลดไฟล์รูปโต๊ะนั้น
   - **ดาวน์โหลดทุกโต๊ะ (.zip):** ไฟล์รูปทุกโต๊ะในไฟล์เดียว ส่งร้านพิมพ์ทำป้ายตั้งโต๊ะ/สติกเกอร์ได้
3. **ติดตั้ง:** เคลือบพลาสติกหรือใส่ป้ายอะคริลิก ติดให้ตรงเลขโต๊ะ
4. **ห้ามแชร์รูป QR ออกนอกร้าน:** ใน QR มีรหัสลับของโต๊ะ ถ้ารูปโต๊ะไหนหลุด กด **เปลี่ยนรหัส** บนการ์ดโต๊ะนั้น แล้วพิมพ์แผ่นใหม่ไปติดแทน

## 8. เจอแบบนี้ทำอย่างไร

| เหตุการณ์ | ทำอย่างนี้ |
|---|---|
| มีออเดอร์แปลกๆ เข้าโต๊ะที่ไม่มีลูกค้า | ยกเลิกออเดอร์ เปิดโหมด **ต้องเปิดโต๊ะก่อนสั่ง** และกด **เปลี่ยนรหัส** QR ของโต๊ะนั้น |
| ลูกค้าบอกว่าสั่งไม่ได้ "โต๊ะยังไม่เปิด" | แตะโต๊ะ → **เปิดโต๊ะ** |
| ลูกค้ากดสั่งผิด / สั่งซ้ำ | แคชเชียร์กด **✕** (ยกเลิก) บนการ์ดออเดอร์นั้น เหตุผล "สั่งผิด/กดซ้ำ" (ถ้าครัวทำแล้วต้องให้เจ้าของใส่ PIN) |
| ลูกค้าอยากเปลี่ยนจานที่สั่งไปแล้ว | ยกเลิกทั้งใบแล้ว **สั่งแทนลูกค้า** ใหม่ (ยกเลิกทีละรายการยังทำไม่ได้) |
| ลูกค้าย้ายโต๊ะ | ยังย้ายบิลข้ามโต๊ะไม่ได้ ให้คิดเงินที่โต๊ะเดิม หรือปิดบิลโต๊ะเดิมแล้วสั่งต่อที่โต๊ะใหม่ |
| ของหมดกลางวัน | ปิดสวิตช์ **มีขาย** ทันที (หรือ Ctrl+K พิมพ์ชื่อเมนู → "ตั้งเป็นหมด") ออเดอร์ที่สั่งไปแล้วให้ยกเลิกด้วยเหตุผล "ของหมด" |
| ลูกค้าสั่งเพิ่มระหว่างคิดเงิน | ระบบไม่ยอมปิดบิลด้วยยอดเก่า แตะโต๊ะใหม่ ตรวจยอด แล้วรับเงินอีกครั้ง |
| ลูกค้าสแกน QR แล้วเปิดไม่ได้ | ให้ลูกค้าต่อ WiFi ร้าน ถ้ายังไม่ได้ ตรวจ "ที่อยู่เว็บที่ใส่ใน QR" และไฟร์วอลล์ของเครื่องร้าน |
| ลูกค้าเห็น "QR ของโต๊ะไม่ถูกต้อง" | QR แผ่นนั้นเก่า หรือข้อมูลร้านถูกล้าง: กู้คืนจากไฟล์สำรอง หรือพิมพ์ QR โต๊ะนั้นใหม่ |
| จอครัวไม่มีเสียง | แตะหน้าจอครัวหนึ่งครั้ง |
| ป้าย "ขาดการเชื่อมต่อ" บนหน้าพนักงาน | ตรวจ WiFi ของเครื่องนั้น และตรวจว่าคอมพิวเตอร์ร้านยังเปิดโปรแกรมอยู่ |
| ป้ายแดง "บันทึกข้อมูลลงเครื่องไม่สำเร็จ" | **อย่าปิดโปรแกรม** ตรวจว่าดิสก์เต็มไหม ปิดโปรแกรม sync ที่ล็อกโฟลเดอร์ข้อมูล ป้ายจะหายเอง ระหว่างนั้นกดดาวน์โหลดไฟล์สำรองไว้ |
| ไฟดับ / เครื่องร้านดับ | เปิดเครื่องและโปรแกรมใหม่ ข้อมูลที่ระบบตอบว่าสำเร็จแล้วยังอยู่ ลูกค้ารีเฟรชหน้าแล้วสั่งต่อได้ |
| คอมพิวเตอร์ร้านเสีย | ติดตั้งโปรแกรมบนเครื่องใหม่ เปิดระบบ แล้ว **กู้คืน** จากไฟล์สำรองล่าสุด QR ที่ติดโต๊ะใช้ต่อได้ (ถ้า IP เครื่องใหม่ต่างจากเดิม ให้ตั้ง IP เดิมในเราเตอร์) |
| พนักงานลาออก | **ปิดบัญชี** ทันที |
| ลืม PIN | เจ้าของกด **แก้ไข** ที่พนักงานคนนั้นแล้วตั้ง PIN ใหม่ (เจ้าของลืม PIN ตัวเอง: ดูค่า `STAFF_PIN` ในไฟล์ที่ใช้เปิดโปรแกรม) |
| เปิดโปรแกรมแล้วขึ้น "ระบบเปิดอยู่แล้วในอีกหน้าต่างหนึ่ง" | ใช้หน้าต่างเดิม อย่าเปิดซ้อน |

## สรุปย่อติดผนัง (พิมพ์ส่วนนี้ไปแปะได้)

**ครัว**
1. แตะจอเปิดเสียง
2. **เริ่มทำ → ทำเสร็จ → เสิร์ฟแล้ว**
3. ของหมด: ปิดสวิตช์ **มีขาย**
4. ยกเลิก: แจ้งแคชเชียร์

**แคชเชียร์**
0. ลูกค้านั่งแล้ว: แตะโต๊ะ → **เปิดโต๊ะ** (ถ้าร้านเปิดโหมดนี้)
1. โต๊ะ **ขอเช็คบิล** → แตะโต๊ะ → ตรวจยอด
2. เงินสด: **รับเงินสด** → ใส่เงินที่รับ → ดูเงินทอน → **ยืนยัน**
3. โอน: ให้สแกน QR → **ตรวจเงินเข้า** → **รับโอน / QR** → **ยืนยัน**
4. **พิมพ์ใบเสร็จ** → **เสร็จ**
5. ยกเลิกออเดอร์: เลือกเหตุผลทุกครั้ง ครัวทำแล้วต้องเรียกเจ้าของ

**เจ้าของ (ปิดร้าน)**
1. ปิด **รับออเดอร์ผ่าน QR**
2. **รอชำระ** ต้องเป็น 0
3. นับเงินสดเทียบยอด / ตรวจยอดโอน
4. ดูประวัติการแก้ไข
5. สัปดาห์ละครั้ง: ดาวน์โหลดไฟล์สำรองเก็บนอกเครื่อง
