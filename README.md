# ออเดอร์ไว · ระบบสั่งอาหารผ่าน QR

ลูกค้าสแกน QR ที่โต๊ะ → เห็นเมนูพร้อมรูปและราคา เลขโต๊ะขึ้นอัตโนมัติ → กดสั่งเข้าครัวทันที
หลังร้านมีจอครัว ออกบิล PromptPay จัดการเมนูและรูปอาหาร สรุปยอด และสำรองข้อมูล ไม่ต้อง `npm install`

## เริ่มใช้งาน

ต้องมี Node.js 18 ขึ้นไป (https://nodejs.org)

```
STAFF_PIN=รหัสอย่างน้อย6หลัก node server.js          # Mac / Linux
set STAFF_PIN=รหัสอย่างน้อย6หลัก && node server.js   # Windows (cmd)
```

- หน้าพนักงาน: `http://localhost:3000/staff`
- ที่อยู่สำหรับลูกค้า: `http://192.168.x.x:3000` (มือถือต้องต่อ WiFi เดียวกับเครื่องนี้)

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `STAFF_PIN` | รหัสพนักงาน (ค่าเริ่มต้น 1234 ควรเปลี่ยน) |
| `BACKUP_DIR` | โฟลเดอร์ที่จะคัดลอกไฟล์สำรองไปเก็บอีกที่ (แนะนำ ดูหัวข้อสำรองข้อมูล) |
| `BACKUP_EVERY_MIN` | สำรองอัตโนมัติทุกกี่นาที (ค่าเริ่มต้น 240 = 4 ชั่วโมง สำรองเฉพาะเมื่อมีข้อมูลเปลี่ยน) |
| `PORT` | พอร์ต (ค่าเริ่มต้น 3000) |
| `DATA_DIR` | โฟลเดอร์เก็บข้อมูล (ค่าเริ่มต้น โฟลเดอร์นี้) |
| `TRUST_PROXY=1` | ใช้เมื่อเปิดผ่าน Cloudflare Tunnel (cloudflared ต้องรันบนเครื่องเดียวกัน) ต้องตั้ง STAFF_PIN อย่างน้อย 6 หลัก |
| `ORDER_LIMIT` | ลูกค้าสั่งได้กี่ครั้งต่อนาทีต่อเครื่อง (ค่าเริ่มต้น 8) |

## ตั้งค่าครั้งแรก

1. แท็บ **ตั้งค่า**: ใส่ชื่อร้าน ที่อยู่ เบอร์โทร เลขผู้เสียภาษี (ถ้ามี) เบอร์ PromptPay และจำนวนโต๊ะ ข้อมูลร้านจะขึ้นบนใบเสร็จ
2. แท็บ **เมนู**: แก้เมนูตัวอย่างให้เป็นเมนูจริงของร้าน ใส่รูปอาหาร
3. ถ้าที่อยู่ใน QR เป็น `localhost` ให้ใส่ `http://192.168.x.x:3000` ในช่อง "ที่อยู่เว็บที่ใส่ใน QR"
4. ลองสแกน QR โต๊ะ 1 ด้วยมือถือที่ต่อ WiFi ร้าน ถ้าเปิดได้ค่อยกด "พิมพ์ QR ทุกโต๊ะ"
5. ตั้ง IP ของเครื่องร้านให้คงที่ในเราเตอร์ ไม่เช่นนั้น QR ที่พิมพ์ไว้จะใช้ไม่ได้เมื่อ IP เปลี่ยน
6. แตะหน้าจอพนักงานหนึ่งครั้งหลังเปิด เพื่อเปิดเสียงแจ้งเตือนออเดอร์ใหม่ (เบราว์เซอร์บังคับ)

## จัดการเมนู (แท็บ "เมนู")

- **เพิ่มเมนู**: กด "เพิ่มเมนูใหม่" ใส่ชื่อ ราคา หมวด จุดที่ทำ (ครัวร้อน/เครื่องดื่ม/ของหวาน) คำอธิบาย และรูป
- **รูปอาหาร**: ถ่ายจากมือถือหรือเลือกไฟล์ได้เลย ระบบย่อรูปในเครื่องก่อนส่ง (รูปไม่กี่สิบ KB) รับ JPG, PNG, WebP
- **แก้ราคา**: มีผลกับออเดอร์ใหม่เท่านั้น ออเดอร์ที่สั่งไปแล้วคิดราคาเดิม
- **ซ่อนเมนู**: ใช้กับเมนูตามฤดูกาล ลูกค้าไม่เห็น แต่ข้อมูลยังอยู่ เปิดกลับมาเมื่อไหร่ก็ได้
- **ตั้งเป็นหมด**: ใช้ตอนวัตถุดิบหมดระหว่างวัน ลูกค้าเห็นว่าหมดภายใน 5 วินาที
- **หมวดหมู่**: เพิ่ม แก้ชื่อ เลื่อนลำดับ ลบได้ (ลบได้เมื่อไม่มีเมนูในหมวดแล้ว)
- **ตัวเลือกหมายเหตุ**: ปุ่มที่ลูกค้ากดได้ เช่น ไม่เผ็ด ไข่ดาว แก้ได้ในแท็บเดียวกัน
- หน้าลูกค้าที่เปิดอยู่จะได้เมนูใหม่เอง ไม่ต้องสแกนใหม่

`menu.json` ใช้เป็นเมนูตั้งต้นตอนเปิดระบบครั้งแรกครั้งเดียว หลังจากนั้นแก้เมนูในหน้าเว็บ

## สำรองข้อมูล (แท็บ "ตั้งค่า" > สำรองข้อมูล)

ไฟล์สำรองหนึ่งไฟล์มีครบทุกอย่าง: เมนู รูปอาหาร ยอดขายทุกเดือน การตั้งค่า ข้อมูลร้าน และรหัส QR ทุกโต๊ะ

- **อัตโนมัติ**: ทุก 4 ชั่วโมงขณะเปิดระบบ เฉพาะเมื่อมีข้อมูลเปลี่ยน (ร้านปิดไม่สร้างไฟล์ซ้ำ) เก็บไว้ในโฟลเดอร์ `backups/` ทุกไฟล์ของ 2 วันล่าสุด และวันละไฟล์ย้อนหลังอีก 30 วัน
- **ขนาด**: ไฟล์บีบอัด `.json.gz` ร้านที่ใช้มา 1 ปี (300 บิล/วัน รูป 50 รูป) ไฟล์ละประมาณ 5 MB ใช้เวลาไม่ถึง 1 วินาที ระหว่างสำรองลูกค้ายังสั่งได้ตามปกติ
- **สำรองเอง**: กด "สำรองข้อมูลตอนนี้" เช่น ก่อนแก้เมนูครั้งใหญ่
- **ดาวน์โหลด**: กดดาวน์โหลดไฟล์ไปเก็บใน Google Drive, LINE Keep หรือแฟลชไดรฟ์
- **กู้คืน**: เลือกไฟล์สำรอง (`.json.gz` หรือ `.json` จากเวอร์ชันก่อน) ตรวจรายละเอียด แล้วกดยืนยันสองครั้ง ระบบสำรองข้อมูลปัจจุบันไว้ให้ก่อนเสมอ ระหว่างกู้คืนระบบจะหยุดรับออเดอร์ไม่กี่วินาที ถ้ากู้ไม่สำเร็จ ข้อมูลเดิมไม่ถูกแตะต้อง
- **ย้ายเครื่อง**: ติดตั้งระบบบนเครื่องใหม่ เปิดระบบ แล้วกู้คืนจากไฟล์สำรอง QR ที่พิมพ์ไว้ใช้ต่อได้เลย

ไฟล์สำรองที่อยู่เครื่องเดียวกับระบบไม่ปลอดภัย ถ้าเครื่องเสียหรือหาย ข้อมูลหายหมด
แนะนำให้ติดตั้ง Google Drive for desktop แล้วให้ระบบคัดลอกไฟล์สำรองไปที่โฟลเดอร์นั้นทุกครั้งอัตโนมัติ:

```
BACKUP_DIR="/Users/ชื่อคุณ/Google Drive/My Drive/ordervai-backup" STAFF_PIN=... node server.js   # Mac
set BACKUP_DIR=G:\My Drive\ordervai-backup && set STAFF_PIN=... && node server.js                # Windows
```

หน้าตั้งค่าจะบอกว่าคัดลอกสำเร็จหรือไม่ ไฟล์สำรองมีรหัส QR และข้อมูลร้าน เก็บเป็นความลับ อย่าแชร์

## งานประจำวัน

- **ปิดรับออเดอร์ QR** ตอนร้านปิด: แท็บตั้งค่า → "รับออเดอร์ผ่าน QR" ปิด (พนักงานยังสั่งแทนได้)
- **ปิดบิล**: เลือกโต๊ะ → ตรวจยอด → กด "รับเงินสด" หรือ "รับโอน / QR" สองครั้งเพื่อยืนยัน → พิมพ์ใบเสร็จ
  ถ้าลูกค้าสั่งเพิ่มระหว่างที่กำลังคิดเงิน (แม้หลังกดรับเงินครั้งแรกแล้ว) ระบบจะไม่ให้ปิดบิลจนกว่าจะตรวจยอดใหม่
  ถ้าเปิดระบบด้วย start.bat และมีภาษาไทยในชื่อโฟลเดอร์ ต้องมีบรรทัด `chcp 65001 >nul` (ดูตัวอย่างใน AGENTS.md)
- **ปิดร้าน**: แท็บสรุปยอด ดูยอดเงินสดเทียบกับลิ้นชัก และยอดโอนเทียบกับบัญชี
- **ส่งยอดให้บัญชี**: แท็บสรุปยอด → "ดาวน์โหลดยอดขายเดือนนี้ (CSV)" เปิดด้วย Excel ได้

## ข้อมูลอยู่ที่ไหน

| ที่เก็บ | มีอะไร |
|---|---|
| `data.json` | เมนู การตั้งค่า ออเดอร์ที่เปิดอยู่ รหัส QR ยอดขาย 8 วันล่าสุด |
| `data.json.bak` | สำเนาตอนเปิดระบบครั้งล่าสุด ถ้า `data.json` เสีย ระบบกู้จากไฟล์นี้เอง |
| `images/` | รูปอาหาร |
| `sales/YYYY-MM.jsonl` | ยอดขายทุกบิล แยกรายเดือน เก็บถาวร |
| `backups/` | ไฟล์สำรองอัตโนมัติและที่กดเอง |

## ความปลอดภัย

- QR แต่ละโต๊ะมีรหัสลับของตัวเอง สั่งข้ามโต๊ะหรือเดา URL ไม่ได้
- ราคาคิดจากเมนูในเซิร์ฟเวอร์เสมอ แก้ราคาจากมือถือไม่ได้
- อัปโหลดรูปตรวจเนื้อไฟล์จริง ไม่ใช่แค่นามสกุล ไฟล์ปลอมถูกปฏิเสธ
- กดสั่งซ้ำตอนเน็ตสะดุดจะไม่เกิดออเดอร์ซ้ำ แม้ลูกค้ารีเฟรชหน้าก่อนกดใหม่
- เดารหัส QR ผิดเกิน 30 ครั้งต่อนาทีจากเครื่องเดียวจะถูกพักไว้ 1 นาที
- ออเดอร์และบิลถูกบันทึกลงเครื่องก่อนลูกค้า/พนักงานเห็นว่าสำเร็จ ไฟดับก็ไม่หาย
- ยกเลิกออเดอร์ รับเงิน ลบเมนู และกู้คืนข้อมูล ต้องกดยืนยันสองครั้ง

## ทดสอบระบบ

```
npm test
```

ชุดทดสอบ 52 เคส จะคัดลอกระบบไปโฟลเดอร์ชั่วคราว ไม่แตะข้อมูลจริงของร้าน ควรรันทุกครั้งหลังแก้โค้ด

## ถ้าเปิดโปรแกรมแล้วขึ้นว่า "ระบบเปิดอยู่แล้วในอีกหน้าต่างหนึ่ง"

มีหน้าต่างเดิมเปิดอยู่แล้ว ใช้หน้าต่างเดิม หรือปิดก่อนแล้วค่อยเปิดใหม่ ระบบไม่ยอมให้เปิดซ้อนแม้คนละพอร์ต เพราะข้อมูลจะเขียนทับกันและเลขบิลซ้ำ

## ถ้าหน้าพนักงานขึ้นป้ายแดง "บันทึกข้อมูลลงเครื่องไม่สำเร็จ"

ข้อมูลล่าสุดยังอยู่ในโปรแกรม อย่าเพิ่งปิดโปรแกรม สาเหตุที่พบบ่อยคือดิสก์เต็ม หรือมีโปรแกรมล็อกไฟล์ `data.json` อยู่
(เช่น ตั้งให้ Google Drive sync โฟลเดอร์ข้อมูลโดยตรง ควรใช้ `BACKUP_DIR` แทน) แก้สาเหตุแล้วป้ายจะหายเองภายในไม่กี่วินาที (ระบบลองบันทึกใหม่ให้เรื่อยๆ)
ระหว่างนั้นกดดาวน์โหลดไฟล์สำรองเก็บไว้ก่อน

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `server.js` | เปิดเซิร์ฟเวอร์ ไฟล์หน้าเว็บ รูป และส่งต่อคำขอไป API |
| `lib/config.js` | ค่าตั้งต้นและตัวแปร environment ทั้งหมด |
| `lib/util.js` | ฟังก์ชันช่วย: วันที่ เขียนไฟล์แบบปลอดภัย อ่านคำขอ HTTP |
| `lib/store.js` | ข้อมูลร้าน การบันทึก การตรวจซ่อมข้อมูลเสีย การคำนวณบิล |
| `lib/backup.js` | สำรองและกู้คืนข้อมูล |
| `lib/routes.js` | API ทั้งหมดของลูกค้าและพนักงาน |
| `public/` | หน้าลูกค้า หน้าพนักงาน |
| `test/` | ชุดทดสอบอัตโนมัติ |

## ยังไม่มี

- ยกเลิกทีละรายการในออเดอร์ (ตอนนี้ยกเลิกได้ทั้งใบ), ย้าย/รวมโต๊ะ, ส่วนลด
- ยกเลิกบิลที่ปิดไปแล้ว
- ตัวเลือกเสริมที่มีราคา (เช่น เพิ่มไข่ +10 บาท) และขนาด (ธรรมดา/พิเศษ)
- ใบกำกับภาษีเต็มรูป และโหมดราคารวม VAT แล้ว (ตอนนี้ใบเสร็จแสดงเลขผู้เสียภาษีได้ ควรให้นักบัญชีตรวจรูปแบบก่อนใช้เป็นใบกำกับภาษี)
- แยกสิทธิ์ครัว/แคชเชียร์/เจ้าของ
- เชื่อมเครื่องพิมพ์ใบสั่งในครัว
- ลูกค้าสั่งผ่านเน็ตมือถือโดยไม่ต้องต่อ WiFi ร้าน (ต้องตั้ง Cloudflare Tunnel เพิ่ม)
