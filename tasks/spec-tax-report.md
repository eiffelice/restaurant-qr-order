# Spec: สรุปยอดขายและภาษี รายสัปดาห์ / รายเดือน / เลือกวันเอง (CSV + PDF)

สถานะ: **อนุมัติแล้ว 15 ต.ค. 2026** (ช่วงยาวสุด 366 วัน · ใช้ taxId บอกว่าร้านจด VAT · disclaimer ตามร่าง) · branch `feat/tax-report` (ต่อจาก `feat/storage-refund`)

## Objective

"ออเดอร์ไว" จะขายให้ร้านอาหารหลายร้าน บางร้านจด VAT บางร้านไม่จด เจ้าของร้านต้องส่งตัวเลขให้นักบัญชีทุกสัปดาห์/เดือน
ตอนนี้มีแค่ CSV รายบิลทีละเดือน และรายงานในหน้าจอ (วันนี้/เดือนนี้/ปีนี้) ที่พิมพ์ไม่ได้

เพิ่ม **"สรุปยอดขายและภาษี"** สำหรับเจ้าของร้าน:
- เลือกช่วง: **สัปดาห์** (จันทร์–อาทิตย์) · **เดือน** · **กำหนดวันเอง** (ไม่เกิน 366 วัน)
- ดูสรุปบนหน้าจอ แล้ว **ดาวน์โหลด CSV** (รายบิล หรือ สรุปรายวัน) หรือ **พิมพ์ / บันทึกเป็น PDF** (A4)
- ใช้ได้ทั้งร้านที่จด VAT และไม่จด: แสดงทั้งรายได้และ VAT และเตือนเมื่อข้อมูลไม่สอดคล้องกับสถานะร้าน

**สิ่งที่ไม่ใช่ (ต้องบอกในเอกสารเสมอ):** ไม่ใช่รายงานภาษีขายตามแบบกรมสรรพากร และใบเสร็จของระบบไม่ใช่ใบกำกับภาษี
ใต้หัวเอกสารและท้ายเอกสารมีข้อความ: "เอกสารสรุปเพื่อประกอบการทำบัญชี ไม่ใช่รายงานภาษีขายหรือใบกำกับภาษีตามประมวลรัษฎากร"

## เนื้อหาสรุป

**หัวเอกสาร:** ชื่อร้าน ที่อยู่ เลขประจำตัวผู้เสียภาษี (ถ้ามี) ช่วงวันที่ วันเวลาที่ออกรายงาน คนที่ออก เลขที่ใบเสร็จตั้งแต่…ถึง… (และใบคืนเงิน)

**ยอดรวมทั้งช่วง:**

| บรรทัด | ที่มา (ต่อบิล) |
|---|---|
| จำนวนบิล / ใบคืนเงิน | บิลขาย / `type:'refund'` |
| ค่าอาหาร (ก่อนส่วนลด) | `sub` |
| ส่วนลด | `disc` |
| ค่าบริการ | `svc` |
| **มูลค่าก่อน VAT** | `total − vat` |
| **VAT 7%** | `vat` |
| **ยอดรวมสุทธิ** | `total` (ยอดคืนเงินติดลบหักแล้ว) |
| คืนเงิน | ผลรวมใบคืนเงิน (แสดงแยก) |
| แยกตามช่องทาง | เงินสด / โอน / บัตร / อื่นๆ (`store.paymentsOf`) |
| **VAT แยกบิล** | บิลที่คิด VAT (จำนวน ยอด VAT) / บิลที่ไม่คิด VAT (จำนวน ยอด) |

**ตารางรายวัน:** หนึ่งแถวต่อวันในช่วง (วันที่ไม่มีบิลแสดง 0) คอลัมน์ตามตารางบน

**คำเตือน (ขึ้นบนหน้าจอและในเอกสาร):**
- ร้าน **ไม่มีเลขผู้เสียภาษี** แต่มีบิลที่คิด VAT → "ร้านที่ไม่ได้จด VAT ไม่ควรเก็บ VAT จากลูกค้า"
- ร้าน **มีเลขผู้เสียภาษี** แต่มีบิลที่ไม่คิด VAT → "มี n บิลไม่ได้คิด VAT ตรวจกับนักบัญชี"
- ช่วงที่เลือกมีวันในอนาคต / ไม่มีบิลเลย → บอกตรงๆ

(ใช้ `settings.taxId` เป็นตัวบอกว่าร้านจด VAT เพราะมีอยู่แล้ว ไม่เพิ่มตั้งค่าใหม่ในงานนี้)

## API (เจ้าของเท่านั้น)

- `GET /api/report/tax?from=YYYY-MM-DD&to=YYYY-MM-DD` (to รวมวันนั้น) → `{ from, to, shop:{shop,address,taxId}, totals, vat:{withVat,withoutVat}, byMethod, days:[...], firstNo, lastNo, warnings:[...] }`
  - ตรวจ: รูปแบบวันที่ วันจริง `to ≥ from` ไม่เกิน 366 วัน · ผิด = 400
  - อ่าน sales/ แบบ async ทีละเดือน (กฎข้อ 60) + บิลใน `D.sales` ที่ยังไม่ลงไฟล์ ตัดซ้ำด้วยเลขที่ (ดึงตัวอ่านจาก `/api/report/range` มาใช้ร่วม)
- `GET /api/export.csv?from=&to=&kind=bills|daily` · `month=` แบบเดิมยังใช้ได้ (ไม่ทำให้ของเดิมพัง)
  - `kind=bills` = คอลัมน์เดิมทุกอย่าง (กฎข้อ 66) เพิ่ม "มูลค่าก่อน VAT" ต่อท้ายกลุ่มคอลัมน์ใหม่ (ก่อน "ชำระโดย")
  - `kind=daily` = หนึ่งแถวต่อวัน + แถว "รวม" ท้ายสุด ชื่อไฟล์ `summary-2026-10-06_2026-10-12.csv`
  - audit `report.exported` (ช่วง ชนิด จำนวนแถว)

## หน้าจอ

- แท็บสรุปยอด (เจ้าของ): ปุ่ม **"สรุปยอดขายและภาษี"** เปิดหน้าต่าง `#tax-dlg` (นอกส่วนที่วาดใหม่ วันที่ที่เลือกไม่หายเมื่อมีออเดอร์เข้า กฎข้อ 26/32)
- ในหน้าต่าง: เลือก สัปดาห์นี้ / สัปดาห์ก่อน / เดือนนี้ / เดือนก่อน / กำหนดเอง (`<input type=date>` 2 ช่อง) → ตารางสรุปแบบย่อ + คำเตือน
- ปุ่ม: **CSV รายบิล** · **CSV สรุปรายวัน** · **พิมพ์ / บันทึก PDF**
- PDF: ใช้ `printMode()` โหมดใหม่ `doc` กระดาษ A4 (`@page doc`) ไม่แตะใบเสร็จ 80 มม. หรือแผ่น QR · ตัวหนังสือดำบนขาว ตารางรายวันขึ้นหน้าใหม่ได้ หัวตารางซ้ำทุกหน้า
- Ctrl+K: คำสั่ง "สรุปยอดขายและภาษี"

## Project Structure / Code Style

- `lib/routes.js`: ตัวอ่านยอดขายตามช่วงเวลา (ใช้ร่วมกับรายงานเดือน/ปี) `taxSummary()` `GET /api/report/tax` และ CSV ช่วงวันที่
- `public/staff.html`: `#tax-dlg` สร้างตาราง/เอกสารด้วย textContent หรือ `esc()` (ชื่อร้าน ที่อยู่ มาจากผู้ใช้ กฎข้อ 9) CSS โหมดพิมพ์ `pm-doc`
- `test/api.test.js` describe "สรุปยอดขายและภาษี" · `qa/browser.js` เคส `taxreport`
- แบบโค้ดเดิมทุกอย่าง ไม่มี dependency ใหม่ (กฎข้อ 15)

## Testing Strategy (เขียนเทสต์ก่อน)

- ยอดทั้งช่วงตรงกับผลรวมรายบิลเอง: บิลมี/ไม่มี VAT, ค่าบริการ, ส่วนลด, ใบคืนเงิน (หักยอดและนับแยก)
- สัปดาห์จันทร์–อาทิตย์ ข้ามเดือน (บิลในไฟล์ sales/ สองเดือน) ตัดซ้ำบิลที่อยู่ทั้งไฟล์และ `D.sales`
- วันไม่มีบิลมีแถว 0 · ช่วงผิด/เกิน 366 วัน = 400 · บทบาทอื่น = 403
- คำเตือน VAT ทั้งสองแบบ
- CSV: `kind=bills` คอลัมน์เดิมไม่เลื่อน "มูลค่าก่อน VAT" ก่อน "ชำระโดย" · `kind=daily` แถวรวมท้ายสุดตรงกับ API · `month=` แบบเดิมได้ผลเหมือนเดิม · ค่าที่ขึ้นต้น = + - @ ผ่าน `q()` (กฎข้อ 14)
- เบราว์เซอร์: เลือกสัปดาห์ก่อน → ตาราง → ดาวน์โหลด CSV ได้ไฟล์ → PDF A4 มีชื่อร้าน ช่วงวันที่ ยอดรวม ข้อความ "ไม่ใช่รายงานภาษีขาย" · ออเดอร์เข้าระหว่างเปิดหน้าต่าง วันที่ที่เลือกไม่หาย · มือถือไม่ล้นจอ · a11y ผ่าน

## Boundaries

- **ทำเสมอ:** คำนวณที่เซิร์ฟเวอร์ (หน้าเว็บแค่แสดง) · อ่านไฟล์แบบ async · ข้อความ disclaimer ในเอกสาร · audit ตอนส่งออก
- **ถามก่อน:** เพิ่มตั้งค่า "ร้านจด VAT" แยกจาก taxId · โหมดราคารวม VAT · ทำเป็นแบบฟอร์มรายงานภาษีขายของสรรพากร
- **ห้าม:** เรียกเอกสารนี้ว่ารายงานภาษีขาย/ใบกำกับภาษี · เปลี่ยนสูตรเงินเดิม · `readFileSync` ไฟล์ทั้งปีใน handler · โหลดไลบรารี PDF จากเน็ต

## Success Criteria

1. เจ้าของเลือกสัปดาห์/เดือน/ช่วงวันเองได้ ตัวเลขบนหน้าจอ = CSV = PDF = ผลรวมจาก sales/
2. CSV เปิดใน Excel ภาษาไทยไม่เพี้ยน (BOM) CSV รายบิลแบบเดิมยังใช้ได้
3. PDF A4 อ่านง่าย มีหัวเอกสาร ยอดรวม ตารางรายวัน คำเตือน และ disclaimer
4. ร้านจด VAT / ไม่จด VAT ได้คำเตือนที่ถูกต้อง
5. `npm test`, `qa/browser.js all`, `qa/a11y.js`, `qa/money.js` ผ่านทั้งหมด

3. **ข้อความ disclaimer** ตามที่ร่างไว้ หรืออยากปรับ
